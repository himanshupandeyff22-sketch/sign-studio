# Learning reference audit — 16 October 2026

Scope: Start ASL, Alison and Udemy, requested as references for Sign Studio.
Only public pages were read. No registration, purchase, private endpoint,
course download, media extraction, or contact with a provider occurred.

| Source | Direct public evidence | Reuse decision |
| --- | --- | --- |
| [Start ASL](https://www.startasl.com/terms-and-policies/) | Public navigation separates courses, dictionary, resources and Deaf culture. Terms describe copyrighted lessons/media and require permission for reproduction or distribution. | Added an external learning link. No lesson, sign video, dictionary text or animation imported. |
| [Alison ASL fundamentals](https://alison.com/course/american-sign-language-fundamental-concepts) | Lists learning outcomes involving sign-language linguistics, ASL variation and interpretation. [Terms](https://alison.com/about/terms-of-use) limit content access to personal educational use and prohibit repackaging course materials on another platform without agreement. | Added an external course link. No course material imported. |
| [Udemy / Able Lingo ASL](https://www.udemy.com/course/asl-first-500-basic-signs/) | Course page describes vocabulary practice/review, handshape, position, movement and facial expressions. The public [terms index](https://www.udemy.com/terms/) was readable; following its Terms of Use link returned navigation without the substantive terms in this research tool. No asset-specific redistribution license or downloadable rig/motion library was established. | Added an external course link. No permission to reuse course media was assumed; no video, model or animation imported. |

Interaction decisions informed by these references: a clearly bounded beginner
entry point, explicit review before practice/playback, visible learning scope,
and separation between a vocabulary list and language grammar. These are our
own product decisions, not copied page designs, lesson text, or lesson content.

No site supplied new reusable sign data in this pass. The animation registry,
concepts, aliases and vocabulary manifest were not expanded or re-labelled.
The existing 3D-LEX recordings remain under their recorded CC BY 4.0 notices;
all previous review gates, senses and provenance are retained. Learning from a
course does not validate an imported animation. Fluent-signer review and
retargeting checks remain necessary before default approval.

The website lists these as external learning references, not project partners,
endorsers, dataset providers or evidence of this prototype's accuracy.
